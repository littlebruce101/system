# Cordelia 🌙

## Purpose
Cordelia is the orchestration and prompt-engineering toolkit.  
It manages workflows, system prompts, and ecosystem cleanup utilities.

## Scope
- Independent toolset (not part of Flamekeeper core).
- Interfaces only through **Bridge → Aegis protocol**.
- Assists in structuring prompts, cleanups, and forwardable packages.

## Safeguards
- Cannot alter Flamekeeper Codex, Vault, or Aegis directly.
- All outputs filtered through Aegis sovereignty.

## Usage
1. Use prompt templates in `templates/`.
2. Run cleanup scripts as needed (`cleanup/`).
3. Forward outputs for Bridge review before Codex entry.

---
**Note:** Cordelia is a *tool*, not a Flamekeeper entity.
